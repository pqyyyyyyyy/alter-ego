# Alter-Ego

端侧虚拟形象交互运行时。在 8 TOPS 边缘 AI 开发板上实现多模型协同的实时语音视觉交互。

## 这个项目解决什么问题

同类的虚拟形象对话项目大多运行在配备独立显卡的 PC 上。把这套体验搬到算力受限的边缘设备，
核心矛盾是多个模型要争抢同一块 NPU 与有限内存：人脸检测、人脸特征提取、语音识别、
语音合成、语言模型需要并发运行，而全部常驻则资源不足，按需加载则模型加载耗时造成卡顿。

本项目的工作集中在这个矛盾上。

## 核心特性

- **多模型协同调度**：以交互状态机驱动的 NPU 资源仲裁与模型驻留管理
- **本地人格层**：云端模型负责内容生成，板上小模型负责口吻赋予与情绪判定
- **多用户识别**：人脸特征绑定独立记忆档案，仅存特征向量，数据不出设备
- **形象可替换**：角色资产与引擎解耦，内置授权字段校验
- **异构分工**：NPU 承载视觉与语音模型，CPU 承载语言模型，物理隔离避免争抢

## 运行环境

- 硬件：Ascend 310B 系列边缘 AI 开发板（8 TOPS INT8，16GB）
- 系统：Ubuntu / openEuler aarch64
- 运行时：CANN 7.0
- Python：3.9+

## 项目结构

| 目录 | 说明 |
|---|---|
| `src/alter_ego/contracts.py` | 模块间接口契约 |
| `src/alter_ego/perception/` | 人脸检测、特征提取、身份比对 |
| `src/alter_ego/voice/` | VAD、语音识别、语音合成 |
| `src/alter_ego/persona/` | 人格卡、示例池、口吻改写 |
| `src/alter_ego/llm/` | LLM 抽象层，多后端可切换 |
| `src/alter_ego/scheduler/` | 多模型协同调度 |
| `src/alter_ego/server/` | FastAPI + WebSocket 服务 |
| `web/` | 前端渲染 |
| `characters/` | 角色包（人格卡 + 示例池 + 素材） |
